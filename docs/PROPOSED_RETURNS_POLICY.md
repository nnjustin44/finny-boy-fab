# Proposed Returns Policy — Owner Review Draft

> **UNAPPROVED DRAFT — NOT ACTIVE.** This document is for the business owner's review only. It is not linked from the storefront and must not be treated as a customer promise. No return window, custom-order exception, cancellation cutoff, return-shipping rule, or refund-processing target below has been adopted. Approve, edit, or reject each decision before publishing a customer-facing policy.

This is an operational drafting aid, not legal advice. Check the final policy against applicable federal and state law and the shop's actual production and support process before publication.

## Decisions for the owner

| Topic | Proposed options to consider | Owner decision |
| --- | --- | --- |
| Standard, non-personalized items | Allow a return request within **14 days** or **30 days** after delivery. Consider limiting discretionary returns to unused items in resalable condition, with all components included. Decide whether original packaging is required or merely preferred. | Pending |
| Personalized or custom work | Possible rule: no change-of-mind returns once personalized/custom work has begun. Preserve a remedy for an item that is damaged, incorrect, or otherwise covered by applicable law. Decide whether custom work can be canceled before production starts. | Pending |
| Cancellation before production | Possible rule: a customer may cancel for a full refund until production begins. Define what “production begins” means in practice (for example, before the board is cut or assembled), and decide how the customer can submit a cancellation request. | Pending |
| Return shipping | Options include customer-paid shipping for a discretionary change-of-mind return, or shop-paid shipping for a confirmed damaged/incorrect item. Decide whether to provide a label or reimburse reasonable tracked postage, and how to handle an item that cannot safely be shipped back. | Pending |
| Damage or incorrect item | Ask customers to contact the shop promptly with the order reference and photos of the item and packaging. Consider a **48-hour** or **7-day** request window after delivery, while preserving any non-waivable rights. Confirm which working contact channel is monitored before adopting a response expectation. | Pending |
| Refund timing | Possible operating target: after a discretionary return is received and inspected, submit the approved refund to the original payment method within **5 business days**. Decide whether to use another target. The bank or card issuer may take additional time to post it; do not promise a posting date the shop cannot control. | Pending |
| Return condition and packaging | Decide whether items must be unused, unmodified, and returned with included accessories; decide how ordinary inspection differs from use. | Pending |
| Exceptions and remedies | Decide how to handle carrier damage, lost packages, defects, wrong options, partial orders, and cases where return shipping is impractical. | Pending |

These are choices for review, not recommendations that any particular window or exception is legally required or suitable for this business.

## Customer-facing draft structure — do not publish as-is

After the decisions above are approved, the published policy should state, in plain language:

1. Which products may be returned and the deadline measured from delivery.
2. The condition required and how to request a return before sending an item back.
3. Which personalized or made-to-order items have different change-of-mind eligibility, and what remedies remain for damaged, incorrect, or nonconforming items.
4. The point before which an order can be canceled, how to request cancellation, and what happens if production has already begun.
5. Who pays return shipping in each case and whether a return authorization or label is required.
6. How and when an approved refund is initiated, which payment method receives it, and that bank posting time can vary.
7. A working contact route that customers can actually use.

Do not replace those decisions with phrases such as “depends on circumstances” once the policy is intended to govern real orders. The shop should also make the approved policy available before checkout and retain the version shown for each order.

## Reference

The FTC's Mail, Internet, or Telephone Order Merchandise Rule addresses shipment timing and delayed-shipment notices, consent, cancellation, and prompt refunds. It is not a general retail return-window rule. Apply its requirements to shipping delays independently of any discretionary returns policy: [FTC Business Guide](https://www.ftc.gov/business-guidance/resources/business-guide-ftcs-mail-internet-or-telephone-order-merchandise-rule).
